# LowLag

Удалённое управление и игра на компьютере друга через интернет с минимальной задержкой.
Один вводит 9-значный код другого, тот нажимает «Разрешить», и через несколько секунд
открывается картинка с его экрана.

## Как это устроено

```
 ПК друга (хост)                                         Ваш ПК (клиент)
┌──────────────────────┐                               ┌──────────────────────┐
│ Sunshine             │  видео / звук / ввод (UDP)    │ Moonlight            │
│ захват + NVENC/AMF/  │ ◄───────────────────────────► │ аппаратное           │
│ QuickSync            │                               │ декодирование        │
│        ▲             │                               │        ▲             │
│   10.213.x.1         │                               │   10.213.x.2         │
│ ┌────────────────┐   │  прямой зашифрованный UDP-    │ ┌────────────────┐   │
│ │ LowLag туннель │◄──┼──────── туннель (P2P) ────────┼─► LowLag туннель │   │
│ └────────────────┘   │                               │ └────────────────┘   │
└──────────────────────┘                               └──────────────────────┘
             ▲      сервер знакомства (только обмен адресами по коду)     ▲
             └──────────────────── ntfy ─────────────────────────────────┘
```

* **Видео** кодирует Sunshine на видеокарте (NVIDIA / AMD / Intel) в режиме минимальной
  задержки, с прямой коррекцией потерь (FEC). Декодирует Moonlight, тоже аппаратно.
* **Сеть** — своя (`core/`): компьютеры находят друг друга по коду, пробивают NAT
  (STUN + UPnP + одновременная отправка) и соединяются напрямую, без серверов посередине.
  Пакеты шифруются ChaCha20-Poly1305, заголовки скрыты — трафик не похож на VPN.
  Туннель добавляет к задержке ~0,01 мс.
* **Перед запуском** замеряется скорость канала, битрейт подбирается так, чтобы не было
  потерь (настройка «Качество → Авто»).

## Структура

| Папка | Что внутри |
|---|---|
| `core/` | Сетевое ядро: коды, шифрование, STUN, пробивка NAT, туннель, замер скорости |
| `engine/` | Логика сеансов: запрос/разрешение, сопряжение, запуск потока; Windows-часть в `engine/src/win.rs` |
| `app/ui/` | Интерфейс (HTML/CSS/JS, шрифты Onest и Unbounded) |
| `app/src-tauri/` | Приложение Tauri и установщик (NSIS) |
| `.github/workflows/build.yml` | Автосборка установщика на серверах GitHub |

## Сборка

Каждый push в `main` запускает GitHub Actions: тесты на Linux, затем сборка на Windows.
Готовый установщик появляется на странице **Releases → preview** (`LowLag-Setup.exe`).

Локально (нужны Rust и Node.js): положить `sunshine.msi`, `wintun.dll` и папку `moonlight/`
в `resources/` (см. workflow), затем `cd app && npx @tauri-apps/cli@2 build`.

Тесты: `cargo test -p llcore -p llengine` (включают полный сценарий двух компьютеров в памяти).

## Тест вдвоём

1. Оба ставят `LowLag-Setup.exe` (Windows покажет предупреждение SmartScreen: «Подробнее →
   Выполнить в любом случае» — установщик пока не подписан).
2. Друг (чей ПК будет управляться) открывает LowLag и диктует свой код.
3. Вы вводите код → друг нажимает «Разрешить» → первый раз Moonlight попросит нажать OK
   после сопряжения → открывается поток.
4. Если что-то не так: Настройки → «Сохранить отчёт в Загрузки» у обоих.

## Что дальше

* Свои серверы-посредники (в СНГ, Европе и США) — на случай, когда прямое соединение
  невозможно (двойной CGNAT); свой сервер знакомства вместо публичного ntfy.
* Работа в трее и как служба, чтобы к ПК можно было подключиться без открытого окна.
* Подпись установщика, автообновление, Steam-сборка.
